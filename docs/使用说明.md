# 微信风聊天 · 使用说明

面向**插件使用者**。安装/卸载见 [README](../README.md)，字段细节见 [配置字段](配置字段.md)，代码结构见 [代码导读](代码导读.md)。

## 它能做什么

把 DSH 的会话区改成微信样式（用户消息在右、助手消息在左，两边都有头像），并按**本轮用了哪些工具**自动换助手那一侧的头像；还可以给每个会话单独开一个「角色头像」。头像能调大小、圆角、背景色（纯色或透明）、点开看大图，也支持 GIF。

它**只改外观**：Markdown、代码高亮、流式输出、复制、重试、工具折叠卡片全部还是 DSH 原生渲染。

## 五分钟上手

打开方式：设置 → 插件 → 「微信风聊天」→ 配置面板。设置页分四个页签：**头像 / 聊天外观 / 工具规则 / 头像方案**，
顶部「**正在编辑**」显示当前在改哪一份方案（默认方案＝旧版的全局设置）。

### 1. 配头像

- 点圆形预览图（或「上传」）选一张本地图片 → **屏幕正中会弹出独立裁剪窗** → 点「应用裁剪」才生效。裁剪窗里的操作：
  - **正方形选框**默认落在图片中央；**框内拖动**移动选区；**拖四角手柄**等比例放大/缩小选区（对角固定）；
  - **右键按住拖动任意位置**（包括框内和手柄）＝移动图片，选框在屏幕上不动；左键在选框外的遮罩上也可拖动图片；**滚轮**或下面的**缩放滑条**缩放图片（框的位置与大小保持不变）；
  - 选区会被约束在图片内（框内不会露出空白），图片平移/缩小碰到边界就停；「**复位**」回到中央最大正方形；
  - 舞台空白使用黑底，导出仍从原图取样，黑底不会写入图片。输出是**完整方形 PNG**，头像的圆角/圆形只是预览遮罩，不会把透明角烘焙进图片。
- **取消**、按 **Esc**、点**暗色遮罩**都不保存，也不会改动原来的头像。
- 也可以直接在输入框里粘图片 URL。
- 传 **GIF** 会直接保存并保留动画，**不弹裁剪窗**。即使系统给出的文件类型不对、甚至没有 `.gif` 后缀，插件也会读文件头认出来。
- 想把 GIF 变成静态图，点「**转静态裁剪**」并确认——只有你主动点才会转，不会自动 PNG 化。

### 1.1 每轮头像会保留（2.4.0）

- **同一个聊天里，已经出现过的轮次保留它当时用的头像**：你之后换头像图片、改工具规则、换头像方案、甚至把源方案删掉，**旧消息的头像都不会跟着变**；新的设置从**下一轮**开始生效。
- **只有头像身份被保留**（图片、字母，以及决定头像的工具规则 / 分类头像 / 角色头像 / 角色标记开关）。**外观仍然是即时的**：改大小、圆角、头像背景、描边、气泡、主题、时间戳，旧消息立刻跟着变。
- 工具头像在本轮内仍然会随工具运行状态动态切换（最后匹配的工具优先、跑完回角色头像）。
- 存储位置：插件自己的浏览器数据库（IndexedDB，`dsh-wx-chat/avatar-history`）。**同一张图跨多轮只存一份**，不占你的方案库配额；导出的方案文件里不含会话与历史。
- **两条诚实的限制**：
  1. 这功能生效**之前**就已经被换掉的旧图片找不回来（那时只留下旧图片的字节）——本功能读到的是"首次读取时能拿到的当前头像"。
  2. 用 **URL** 当头像时只记住这个地址；如果同一个地址指向的远端图片自己变了，历史头像也会跟着变（插件不会去下载/抓取远端图片）。
- 如果浏览器数据库不可用（例如配额满、被其它窗口占用），当前窗口显示**照常**，设置页会提示一次「重开可能丢失」；插件不会因此挡住消息，也不会自动删掉你的历史。

### 2. 调外观

- **气泡毛玻璃（2.6.0）**：气泡底约 88–94% 不透明 + 轻微模糊/提色，背后内容会柔化地透出来，但**文字始终清晰**（文字本身不透明，不做整块透明处理）。
  - **开关**：设置 → 插件 → 微信风聊天 → **聊天外观 → 气泡 → 毛玻璃**。关掉就完全回到原来的近不透明底色（实测 `backdrop-filter: none`、alpha 0.94）。
  - **样式**：预览卡可选 **素笺 / 猫猫信笺 / 莉栀小笺 / 田园来信 / 鱼鱼·潮汐来信 / 猫耳鱼鱼 / 澄蓝水波**。卡片中的样例都为 **76×40 CSSpx**，实际聊天按正文自然伸展。
  - **完整皮肤**：猫身体本身就是气泡；莉栀款使用白龙、翅膀与裙边；田园款用雏菊、格纹和布艺；鱼鱼两款分别为海浪珍珠与猫耳星光。四套花边由 SVG 单元等大小连续铺排，蝴蝶结与角花独立保持比例。人物保持原比例、跨在气泡下拐角外侧；正文不再为人物让出整列，左右留白一致，外侧间距防止盖住下一条消息；猫身与猫脚保留弹性，文字居中在肚子区域。新增澄蓝水波使用蓝色波光与白字。
  - **夜间适配**：六套完整皮肤各有独立昼/夜配色或素材。跟随 DSH 主题，或使用方案的浅/深主题选择。夜间写字面变深、文字变浅，角色仍清楚，不会把整张图片统一压黑。
  - 完整皮肤的配色与轮廓由皮肤控制，**用户/AI 气泡色、气泡圆角、毛玻璃**暂时禁用；**最大宽度仍可调**，头像设置不受影响。保存的旧值不会删除，切回「素笺」即可恢复。
  - 旧「经典 / 描边」自动并入素笺，旧方案仍可导入；具名方案可保存七种样式。
  - 系统/浏览器不支持 `backdrop-filter` 时自动退回近不透明底色——只有"看得更实"，不会更糊。
  - 自定义气泡颜色时，插件按你的颜色派生玻璃底：先按 90% 不透明度试算，若文字对比不够（把气泡叠在纯黑/纯白最坏情况上算）就自动提高不透明度，必要时直接用不透明色。**你保存的颜色不会被改动**。
  - 思考（reasoning）行、代码块、以及聊天页本身**不加玻璃**。行内代码使用半透明小框与高对比文字，深色完整皮肤的小框也会降低亮度；多行代码块与高亮保持原样。
  - 注意：换图片/改规则/换方案只影响**下一轮**，但气泡外观（大小、圆角、背景、气泡色、玻璃、样式）一直是**即时**生效的。

- **鲸鱼海浪开关（全局）**：在「聊天外观 → 界面美化（全局）」开关美化。开启后覆盖整个 DSH 的标准开关，关闭后恢复宿主原样；灰色轨道原子表示关，蓝色思索鲸鱼尾巴表示开，海浪铺在轨道里。修改它不会切换头像方案，也不跟随预设变化。此设置不包含在方案导入/导出中。自绘的非标准控件不强行改造。

- **大小**：24–96px 滑条。聊天里所有头像（用户 / 助手 / 工具 / 角色）一起变，行间距与所在行的最小高度跟着走，不会压到相邻消息。
  **窄窗口（宽度 ≤480px）里头像实际显示封顶 32px**，给气泡留空间——这是 CSS 媒体查询决定的，配置值仍然保留。
- **预览大小**：滑条旁边的按钮，打开一个居中弹窗，用**你当前的真实头像**（含 GIF）画一段样例会话，
  可以在弹窗里直接拖大小和圆角看效果；底下会写「配置值 Npx ｜ 当前窗口实际显示 Mpx」，窄窗口封顶时会明确提示，不会让人以为拉了没反应。
- **圆角**：0–100 滑条，**左端＝方形，右端＝圆形**：`0` = 直角、`50` = 圆角方形、`100` = 圆形（默认）。
- **头像背景**：纯色设置。默认就是原来的品牌蓝；可以换任意纯色，也可以点「**透明**」让背景真的透明。
  - 背景只作用在**图片/字母的透明区域**，不会去掉图片自带的底色。
  - 字母头像会按背景深浅自动切换文字色，浅色背景上也看得清。
  - 这里只做纯色，**不提供背景图片/贴图**。
- **头像描边**：头像外圈的一道描边，颜色独立设置，可以点「无描边」关掉。
- 头像圆角和气泡圆角是两项独立设置，互不影响。

### 3. 让工具换头像

- 「工具头像」里给四类各传一张：**搜索/浏览**、**读文件**、**写文件**、**命令/测试**。
- 想按具体工具名精细控制，就在「具体工具名规则」里填精确名字（例如 `browser_run`、`apply_patch`、`web_search`）再「添加」、传图。
- 优先级：**具体工具名规则 > 类型 > 默认头像**；留空就是没配。
- **每一轮独立结算**：这一轮里最后一个匹配到的工具头像就是本轮头像；下一轮没有匹配的工具时回落默认头像，**不继承上一轮**。
- 按工具调用的**开始顺序**更新；较早调用的工具晚一些完成，也不会把头像切回较早的选择。

### 4. 点头像看大图

直接点聊天里的头像弹出大图；按 **Esc**、点暗处、或点右上角 ✕ 都能关。只有头像那一小块会响应，
气泡里的链接、代码复制、工具控件不受影响；合并头像时被隐藏的头像行、以及空行点上去不会弹。

### 5. 角色头像

- 入口是**输入框按钮区（发送按钮那一排）里的「角色头像」按钮**，上面写着当前模式，点开就是设置小弹窗——
  **不用跳回设置页**，在里面可以直接选模式、看角色头像预览、上传/裁剪/清除角色图片。
- 模式说明：
  - `开启`：从**当前还没结束的那一轮**开始用角色头像（工具运行的那几秒临时换成工具头像，跑完自动换回）。
  - `关闭`：从当前这一轮开始不用角色头像。
  - `自动`：跟随助手回复里的标记（见下）。弹窗里有「复制标记约定」按钮。
- 弹窗里的状态说明会随实际情况变：没设角色图会直说「尚未设置角色头像，仍显示默认头像」；有正在跑的轮次会说「本轮即时生效」；
  空闲时说明「下条回复生效，历史消息保持原样」。
- **手动模式切换只从当前未结束轮或下一轮生效**，之前聊完的历史仍按原有模式边界计算；**每个会话各记各的**。角色图片、工具规则等头像身份配置按「智能体预设 → 头像方案」绑定选择，也可以给单个会话做临时覆盖；更换这些配置从下一轮生效，已经出现过的轮次保留原来的身份。
- 插件**只控制头像**：它不会因为你说了「你是一只猫娘了」之类的自然语言就自动换图，也不会替你修改角色设定/提示词。
  想让助手扮演角色，直接在聊天里告诉它就行；想让头像跟着换，就用下面的标记或手动开「开启」。

### 6. 头像方案（默认跟随智能体预设）

- **默认路径是「智能体预设 → 头像方案」**：在「头像方案」页签顶部的「智能体预设 → 头像方案」里，给某个预设挑一个方案。
  之后**所有跟随该预设的会话**都会自动用它；调整这里的头像方案绑定会即时生效，不需要重发消息。已有会话实际使用哪个智能体预设由 DSH 决定，本插件不会替它切换。
- 列表里显示的是宿主**真实的预设 ID 与名称**（不猜名字）；预设改名后按稳定 ID 仍然有效。
- 在「头像方案」页签里：填名字 → 「从当前方案创建」；每行可以**改名 / 复制 / 导出 / 删除**，也能**导入**别人分享的 JSON。
- 聊天**输入框旁的「头像方案」**按钮是**本会话的临时例外**：给当前会话临时选一个，
  点「**跟随预设**」取消；选「**默认方案**」是一条**明确的覆盖**（和「跟随预设」不是一回事）。
- **生效顺序：本会话临时选择 > 本会话实际预设的绑定 > 旧默认方案。**
  没有预设信息的老会话、拿不到预设 ID 的会话、预设没有绑定方案时，都用默认方案（界面会说明原因）。
- **修改同一个方案会影响所有使用它的会话与预设**——想让 A 会话和 B 会话互不影响，就给它们分开用不同方案。
- **切换方案时，大小、圆角、背景、气泡和主题立即生效**；图片、字母及头像规则从下一轮生效。
  历史轮次引用当时的头像身份，同一图片和身份配置共享保存，不会在每一轮复制大图。
- 「默认方案」不能改名/删除（可以复制、导出）；**删除正在被使用的方案**时，界面会说明清理了
  「N 个会话的临时选择、M 个预设的绑定」，它们按优先级回落，不会静默丢设置。
- 导出文件里只有方案名和这一套外观设置（头像原图数据也在里面，GIF 保留原字节），
  **不含预设绑定、聊天记录、会话 ID，也不含角色模式历史**。导入一律作为**新方案**加入，不会覆盖已有方案。
- 会话的**角色模式（自动/开启/关闭）不属于方案**，还是各会话按轮次边界单独记录。
- **不写 DSH**：只读预设的 ID/名称做绑定，不会切换会话实际使用的智能体，也不改预设、模型或提示词。
- 读不到预设名单（宿主没有这个服务 / 临时失败）时：界面会说明并给「重试」按钮，
  **已保存的绑定照样按 ID 生效**（名字临时显示成 ID 本身），名单恢复了就自动补上名字。

### 7. 预览弹窗里的「恢复到打开时」

在「预览大小」弹窗里调了大小 / 圆角 / 背景 / 描边之后：

- 点「**恢复到打开时**」= 撤销这次打开弹窗后对**这 4 项**做的调整，其它东西（头像图片、工具规则、角色开关、方案绑定）**不受影响**。
- 直接**关闭弹窗**＝保留改动（不是取消）。
- 想全部回到出厂值，请到配置面板点「**把当前方案恢复默认**」——它只重置「正在编辑」的那一份方案，不会清空方案库或会话绑定。

## 标记怎么写

标记必须**自己占一整行**，放在**助手回复正文**里才认（代码块、缩进代码块、引用里的示例都不算，用户消息和思考内容也不算）。

看不见的写法（推荐，原生 Markdown 会把它隐藏）。开启时让助手在回复正文里独立成段写下面一行，前后各留空行：

```
[//]: # (wx-roleplay:on)
```

退出时在后续回复里写：

```
[//]: # (wx-roleplay:off)
```

会显示出来的兼容写法是 `<!-- wx-roleplay:on -->` 和 `<!-- wx-roleplay:off -->`，使用时同样各自独立成行。

不要把开启和退出两行一起放进同一条回复：最后的 `off` 会覆盖前面的 `on`。

- `on` = 从这条回复开始进入角色模式，`off` = 退出。
- 同一轮里写多行，**最后一个有效标记生效**。
- 写了一半（比如只有 `[//]: # (wx-roleplay:on`）不算，不会切换。
- 状态按已加载的助手正文**累计**：出现过 `on` 就一直算开启，直到出现 `off`。
- 配置面板里的「**自动标记识别**」关掉后，标记不再被解析，弹窗里的「自动」会说明已关闭——这时请手动选「开启」/「关闭」。

## 气泡与其它

- **用户气泡色 / 助手气泡色**：各自一个颜色选择器。
- **气泡圆角**：4–20px；**最大宽度**：50–90%（相对会话区宽度）。
- **时间戳**：默认关闭。打开后显示的是**本地近似渲染时间**，不是服务器给出的消息时间。
- **合并头像**：连续同一个角色的消息只保留一个头像。
- **主题**：跟随系统 / 亮色 / 暗色。气泡和弹窗跟随主题；头像描边仍使用单独配置的颜色。

## 失败与排查

| 现象 | 原因与处理 |
|---|---|
| 裁剪头像点击放大后发糊 | 2.3.1 及更早版本只保存 240×240。更新到 2.3.2 后，重新上传清晰原图并裁剪；新版从原图导出最高 1024×1024（受原图有效像素和体积预算限制）。旧头像已丢失的细节无法自动恢复。 |
| 配置面板/弹窗提示「当前窗口已生效，但保存失败」 | 浏览器存储写不进去（常见于图片撑满配额）。**当前窗口仍然生效**，刷新后可能丢失——换更小的图，或改用图片 URL。 |
| 提示「未应用」「没有修改」或图片/方案超限 | 输入或容量检查在提交前拒绝了本次操作，**原来的头像与设置保持不变**。请减小图片或按提示修正后重试；这与“本窗已生效但保存失败”不同。 |
| 弹窗里提示「图片加载失败（可能是无效链接或跨域图片）」 | 直接粘的是远程图 URL 且不允许跨域取像素。改用「上传」选本地图片。 |
| 弹窗里提示「这张图片无法裁剪（跨域图片会被画布拒绝）」 | 同上：图片能显示但不允许导出。改用本地图片，或直接把该 URL 当头像用（不做裁剪）。 |
| 选完图看到「正在读取图片…」很久 | 文件较大或磁盘慢；此时**取消/关闭都不会写入**，可以重新选。 |
| 头像没换 | 检查「工具头像」是否被关掉；该轮工具是否匹配到规则；角色模式是否真的处于开启状态（看按钮上的字与弹窗说明）。 |
| 角色头像一直不出来 | 先在弹窗里确认「角色图片」已配置；再看模式；`自动` 模式下需要助手回复里出现 `on` 标记。 |
| 另一个窗口没跟着变 | 同窗立即生效；其它窗口要等浏览器派发 `storage` 事件（配置与每会话角色模式都会同步）。 |

## 保存失败会怎样

先区分两种结果：提交前被拒绝时，原设置不变；提交已在本窗生效、但浏览器保存失败时，刷新可能丢失本次改动。界面会分别说明，GIF 上传同样如此。

所有会写盘的入口（改配置、上传/裁剪头像、建/改/删/选方案、导入、主题与气泡、恢复到打开时）都会检查写入结果：

- 写入失败时，**在你正在操作的那个界面**显示红字：例如角色弹窗里会写「当前窗口已生效，但保存失败，刷新后可能丢失」。
- 当前窗口**仍然按你的选择显示**（不会假装成功、也不会被旧值覆盖），但**刷新后可能回到上一个状态**。
- 下一次写入成功会自动清掉旧提示。
- 读取失败（存储被禁用 / 数据损坏）会单独说明「当前显示的是默认值」，与保存失败区分开。

## 数据与隐私

- 配置存在浏览器 **localStorage**（键名见 [配置字段](配置字段.md)），属于**当前来源/当前浏览器**的数据，**不等于账号级或跨设备同步**。
- 图片以 data URL 形式保存，或保留你填的图片 URL。**填 URL 时会向该地址发请求**，所以这不是一个「完全离线/无网络」的插件。
- 本插件**没有后端上传接口**，不会把头像上传到任何服务器；也没有任何统计/上报。


## 连续调整颜色与滑条（2.8.4）

颜色、头像大小/圆角、气泡圆角与最大宽度会立即预览，停下约 160ms 或松手后保存。头像外观弹窗与设置面板采用相同方式；关闭弹窗、切换方案或离开设置面板会保留最后的调整。若提示本地保存失败，本窗口仍显示新外观，但刷新后可能丢失。
