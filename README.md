# 微信风聊天（dsh-wx-chat）

DeepSeek Harness 的会话界面插件：把会话区换成微信聊天气泡样式——用户消息在右侧（带头像），
助手消息在左侧（带头像），并按**本轮用了哪些工具**自动切换助手那一侧的头像。

- 纯展示层：不替换任何消息渲染器，Markdown、代码高亮、流式输出、复制、重试、工具调用折叠卡片全部保留原生实现。
- 只控制外观与头像：读取宿主会话快照中的工具信息和助手正文里的约定标记，不根据自然语言猜测角色，不修改角色设定/提示词，也没有后端上传接口。
- **头像方案**：一整套头像与外观设置可以存成具名方案，默认绑定到 **DSH 智能体预设**；单个会话可临时覆盖。支持创建、复制、改名、删除和 JSON 导入/导出，导出不含聊天记录、预设/会话绑定或角色模式历史。
- 当前版本 **2.8.2**。
- **2.8.2 完整气泡皮肤**：可选 **素笺 / 猫猫信笺 / 莉栀小笺 / 田园来信 / 鱼鱼·潮汐来信 / 猫耳鱼鱼 / 澄蓝水波**。新增澄蓝水波（顶部高光、层叠水波与白字）；莉栀、田园、鱼鱼与猫耳鱼鱼改用独立 SVG 花边，按固定大小连续铺排，不再拉伸整张边框图。蝴蝶结、角花和三位角色独立保持比例；角色跨在气泡下拐角外侧，正文左右留白恢复一致，不再为人物空出整列。外侧留出挂件所需间距，避免压住下一条消息。猫猫身体和脚保留弹性，文字落在肚子中央。
- **昼夜两套素材**：完整皮肤跟随 DSH 深浅主题或当前方案的强制主题，夜间使用独立深色写字面、矢量配色与浅色文字，保留角色原画。选择卡的七个样例统一 **76×40 CSSpx**，只缩小预览，不改变真实消息。
- **旧配置保留**：完整皮肤不受用户/AI 气泡色、气泡圆角和毛玻璃影响，这四个控件会暂时禁用；切回「素笺」即可恢复保存的设置。最大宽度和头像设置仍可使用。
- **2.6 功能保留**：裁剪舞台空白为黑底，按住右键从任意位置拖动图片，选框保持固定；黑底不会写入导出图片。
- **全局鲸鱼海浪开关**：「聊天外观 → 界面美化（全局）」中的独立总开关，覆盖 DSH 的标准开关（`role="switch"`）：关闭状态为轨道原子，开启状态为原生思索鲸鱼尾巴，轨道带海浪。保留原有点击、键盘、禁用及无障碍语义。美化设置独立保存，不属于头像方案。
- **版本核对**：已按本机 DSH **0.2.1-rc.2**（build `332895e0f7c9d4dbfb29729f5eb367fa263ff986`）核对依赖、slot、聊天 DOM 标记，并以该版本真实前端 CSS/React 做隔离浏览器验证。宿主未来若改变 DOM 或开关拇指类名，仍需重新核对；这不是对所有后续版本的兼容承诺。
- **素笺毛玻璃外观**（完整皮肤有独立写字面）：user / steering / assistant 气泡与外观预览统一用**约 88–92% 不透明度的有色底 + `blur(10px) saturate(1.1)` + 克制的内侧高光**，文字本身保持 100% 不透明（不对整个气泡用 opacity/filter）。用 `@supports (backdrop-filter: blur(1px))`（含 `-webkit-`）做**渐进增强**，不支持的系统继续用原来的近不透明底色（可读性优先）。自定义气泡色会派生出同样的玻璃底：alpha 从 0.90 起步，在黑/白两个端点背景上合成后若文字对比不足 4.5 就逐步提高 alpha 直到安全（必要时不透明）——**不改你保存的颜色**。reasoning、代码块与页面本身不加玻璃；可在「聊天外观」中关闭。
- **2.4.0 功能**：**每轮头像历史**——同一个聊天里，已经出现过的轮次会保留它**当时**用的头像身份（图片、字母，以及工具规则 / 分类头像 / 角色头像 / 角色标记这些"决定头像"的配置）；之后再换头像图片、改工具规则、换方案或删掉源方案，都**只影响下一轮**，旧轮次不会被重画。
  - **只冻结头像身份，不冻结外观**：大小、圆角、头像背景、描边、气泡、主题、时间戳仍按当前方案即时生效。
  - 存储用插件**自己的 IndexedDB**（`dsh-wx-chat/avatar-history`：图片资产去重 / 头像身份快照 / 轮次映射三个 store）；同一张图跨多轮只存一份，不进 `config-v1`，也不占 6MiB 方案库；导出的方案文件里**不含**会话 ID 与头像历史。
  - **诚实边界**：本功能生效前就已经被覆盖掉的旧图片无法恢复（本功能读到的是"当时的当前头像"）；**远程 URL** 只保留引用，同一 URL 指向的远端图片自己变了无法冻结；持久化失败（无 IndexedDB / 配额 / 被占用）时当前窗口显示照常、设置页给一次提示，**重开可能丢失**。
  - 行内代码使用**半透明小框与高对比文字**：素笺/浅色皮肤为淡白底深色字，深色完整皮肤为低亮度白色半透明底与浅色字，多行代码块与高亮不受影响。

## 最短使用步骤

1. **安装**：先解压，在 DSH 中通过插件管理工具的 `install_bundle` 操作，把含 `package.json` 的本目录作为 bundle 安装。操作名称示意如下（这是 DSH 工具操作，不是 PowerShell/系统终端命令）：

   ```
   plugin_manager install_bundle <本目录的绝对路径>
   ```

   安装后刷新页面即可生效（源码改动也是刷新页面生效，不需要构建步骤）。

2. **打开配置**：设置 → 插件 → 「微信风聊天」→ 配置面板。
3. **配头像**：点圆形预览图或「上传」选一张本地图片 → 在**屏幕正中弹出的裁剪窗**里拖动/缩放 → 「应用裁剪」。
   设置页按「头像 / 聊天外观 / 工具规则 / 头像方案」四个页签分组，顶部「正在编辑」显示当前在改哪一份方案。
4. **调外观**：拖「大小」（24–96px）与「圆角」（0–100）滑条；滑条旁的「预览大小」可以打开样例弹窗对照效果。
   头像背景支持纯色与「透明」。
5. **角色头像**：聊天**输入框旁边**的「角色头像」按钮 → 上传角色图片 → 选「开启 / 关闭 / 自动」。从当前未结束轮开始生效；空闲时从下一轮开始，
   已完成的历史仍按当时的模式边界计算；每个会话各记各的。
6. **按会话选方案**：聊天输入框旁的「头像方案」按钮 → 选一个方案（或「默认方案」）。每个会话各记各的。
7. **卸载**：插件管理器里禁用或移除本 bundle。卸载会清掉本插件注入的样式、根变量、行内头像覆盖、
   观察器、预览层、弹窗宿主与会话作用域变量，不会动宿主的其它样式。

## 头像方案（2.3 新增）

- **默认按智能体预设生效**：每个会话用的是哪个 DSH 智能体预设，就看「预设 → 方案」绑定给了哪个方案。
  绑定在「设置 → 插件 → 微信风聊天 → 头像方案 → 智能体预设 → 头像方案」里维护，列出宿主真实的预设 ID/名称（预设改名后按 ID 仍然有效）。
- **会话级只是临时例外**：聊天输入框旁的「头像方案」里可以给**本会话**临时选一个；点「跟随预设」取消。
  选「默认方案」是一条**明确的覆盖**（≠ 取消覆盖）。
- **生效顺序**：本会话临时选择 > 本会话实际预设的绑定 > 旧默认方案。
- **是什么**：一个方案 = 一整套外观（用户/助手/角色/工具头像 + 大小、圆角、背景、描边 + 气泡、主题、合并头像、时间戳）。
- **默认方案**：就是旧版的全局配置（存在 `dsh-wx-chat/config-v1`），**没有被预设绑定、也没有临时选择的会话都跟随它**，老用户不需要做任何事。
- **自建方案**：存在新键 `dsh-wx-chat/schemes-v1`（含 `presetBindings` 与 `bindings`），可创建/复制/改名/删除/导入/导出。
- **改一个方案会影响所有使用它的会话/预设**；想互不影响就分开用不同方案。
- **删除正在被使用的方案**：界面会说明「有 N 个会话的临时选择、M 个智能体预设的绑定被清理」，它们按优先级回落。
- **会话的角色模式（自动/开启/关闭）不属于方案**，仍然按各自的轮次边界单独记录。
- **导出/导入**：导出内容只有 `format/version/name/config`（**不含**预设绑定、会话 ID、角色模式历史）；导入一律作为**新方案**加入，先完整校验格式与字段类型，坏文件 / 错版本 / 非法结构会被拒绝且不改动现有数据，重名会自动加序号。
- **不会改动 DSH**：只读预设的 ID 与名称用来做绑定，不调用任何切换/设为默认/写入设置的接口，不读预设的组合与提示词，也不会切换会话实际使用的智能体。

## 宿主要求与注意事项

- **运行环境**：用于 DSH 桌面版的客户端界面；`client.js` 依赖宿主注入的 `window.__ModuleLoader__`
  与共享 `react`。共享 `react-dom` 可用时用于 portal，缺失时弹窗使用固定层退化实现。**它不是可以直接 `node` 运行的脚本**。
- **slot 依赖**：注册在 `plugins.bundle.config`（配置面板）与 `conversation.input.right`（会话输入框按钮区）。
  宿主若改了 slot 名或输入区结构，需要跟着调整。
- **选择器耦合**：样式的主钩子是 `data-chat-flow-kind` / `data-chat-turn` 等稳定属性，但气泡、滚动容器等
  规则仍引用宿主当前的 content-hash 类名（构建版本变化会变）。**升级宿主后请按
  [代码导读](docs/代码导读.md) 第 11 节「维护检查」核对**，不要假设跨版本一定兼容。
- **深色模式**：优先使用宿主变量（`body[data-ds-dark-theme]`、`--dsw-alias-*`）；宿主不提供时回落到插件自带的一套成对配色。
- **数据位置**：配置在浏览器 `localStorage`（`dsh-wx-chat/config-v1`、`dsh-wx-chat/roleplay-v1`、`dsh-wx-chat/schemes-v1`），
  每轮头像历史在插件自己的 IndexedDB（`dsh-wx-chat/avatar-history`）。这些都是当前来源/当前浏览器的数据，**不等于账号级或跨设备同步**。
- **网络**：头像可以填远程图片 URL，**此时会向该地址发起请求**；填 URL 或点「上传」都不会把图片上传到任何服务器。
- **时间戳**：打开后显示的是本地近似渲染时间，不是服务器给出的消息时间。

## 开发与验证

- 本插件**没有构建步骤**，也没有 `npm start` / `npm run build` 之类的脚本（`package.json` 里没有 `scripts`）。
  改完源码后让 DSH 重新加载插件 / 刷新页面即可看到效果。
- 本仓库**不包含**历史测试夹具与测试脚本（它们属于开发者本地环境，不在分发包里）。
  若要回归功能，请在 DSH 里重载插件后手动核对：头像切换、裁剪弹窗、GIF 保留动画、角色模式边界、
  以及卸载后界面恢复原生。
- **2.4.0 行内代码修复**：聊天气泡里的**行内代码**（`` `/t 0` `` 这种）此前使用宿主固定浅底，可能出现浅色文字配浅色背景而看不清。现在仅在本插件气泡内使用透明背景、气泡文字色和柔和细边框，随当前气泡与主题显示。**多行代码块（pre / .md-code-block）与插件外的代码保持宿主原样**，等宽字体、复制与选中行为不变。
- **2.3.2 修复**：裁剪保存的头像**分辨率不足**（当时按 240 CSSpx 的预览画布导出，点开大图放大就糊）。现在**预览尺寸与导出分辨率分离**：新版裁剪使用独立舞台坐标取景，导出时按源图选区**从原图重画**到最高 **1024×1024** 的方形 PNG（**位图**受原图有效像素与单头像约 2MiB 预算限制，必要时按 1024→896→768→640→512 逐级降尺寸重画；**SVG 等矢量源**不受 `naturalWidth` 限制，按矢量绘制到 1024）。**旧头像不会自动变清晰**——想看高清效果请重新上传原图并裁剪一次。
- **2.3.1 修复**：助手宽表格原本按宿主正文列向两侧展开，套入气泡后会出现滚动区域错位和内容被裁。现在会将这组宽度、负边距与内边距还原到气泡内，并为用户/助手/引导气泡提供横向滚动。自定义气泡底色时，会按实际文字对比度选择白字、深蓝字或黑字，预览也使用相同颜色；不改保存的底色。
- **2.3.0 包含功能改动**。开发时用 Node 逻辑夹具、桌面客户端产物中的真实 React/ReactDOM，以及本机真实 Cordis 容器验证了方案优先级、导入/导出、作用域隔离、预设服务装配与保存失败处理；也检查了多个标签页同步和窄窗口布局。
- 自动验证在隔离环境完成，未直接操作用户正在运行的 DSH 会话。真实浏览器存储配额、DSH 升级后的兼容性，以及操作系统下载目录写入仍需结合实际环境核对；详情见[代码导读](docs/代码导读.md)。
